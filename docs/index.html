  • 2025년 여성 근로자의 시간당 임금총액은 23,412원으로 남성(31,540원)의 74.2%이며, 2020년(71.4%) 대비 2.8%p 좁혀졌으나 여전히 큰 격차임

  • (근속·경력) 같은 직종·학력·연령대 안에서도 여성의 평균 근속이 짧아(5.8년 vs 8.1년) 격차의 47%를 설명 → 출산·육아기 경력단절이 근속 연동 임금체계를 통해 임금격차로 이어짐
  • (근무부담 보상) 초과근로 비중 차이는 격차의 3.4%만 설명 → ‘위험·장시간 노동 보상’ 가설로 설명되는 부분은 작음
  • (동일 조건 내 격차) 같은 직종·학력·연령대·근속·초과근로 조건을 맞춰도 격차의 51%가 남음 → 동일노동 동일임금 점검이 필요한 영역
□ 정책 제언
  • (경력단절 예방·근속 격차 완화) 육아휴직·근로시간 단축 기간의 근속·호봉 인정 의무화 점검, 남성 육아휴직 확대로 경력단절의 성별 편중 완화 고용노동부·성평등가족부
  • (동일노동 동일임금 점검) 동일 조건 내 잔여 격차를 매년 같은 방식으로 산출해 성별임금 공시·적극적고용개선조치(AA) 사업장 점검 지표로 활용 고용노동부
  • (직무가치 재평가) 같은 직종 안에서 여성이 몰린 하위 직무(예: 보건·복지의 돌봄·간호 보조)의 가치를 숙련·책임·노력·작업조건 기준으로 재평가, 사회서비스 임금 가이드라인부터 적용 성평등가족부·고용노동부
  • (안전보건·근로시간) 위험·장시간 노동에 대한 임금 보상은 격차의 작은 부분 → 위험수당보다 고위험 업종의 재해 자체를 줄이는 투자, 초과근로 의존 임금구조 개선이 우선 고용노동부·한국산업안전보건공단

2. 직종 분리 효과

남녀 직종 분포가 얼마나 다른지 보여주는 던컨 분리지수는 27.1입니다(여성 또는 남성의 27.1%가 직종을 옮겨야 분포가 같아진다는 뜻). 여성 비중이 높은 직종은 서비스, 단순노무, 사무입니다.

시간당 임금격차 8,129원을 직종 간 분포 차이와 같은 직종 안의 임금 차이로 나누면 각각 -6%와 106%입니다 (산업 기준 0%와 100%). 여성이 저임금 서비스·단순노무에도 많지만 상대적으로 임금이 높은 사무·전문가 직종에도 많아, 직종 대분류 수준의 ‘분포 차이’는 서로 상쇄됩니다. 격차는 직종을 고르는 단계보다 같은 직종 안의 직무·직급·근속 차이에서 생깁니다. 직종 내 여성/남성 임금 비율이 가장 낮은 곳은 판매(65%), 산업 중에서는 보건·사회복지(61%)입니다.

직종 대분류(9개)는 의사와 요양보호사를 같은 ‘전문가·서비스’로 묶을 만큼 넓습니다. 따라서 이 결과는 ‘직종 분리 효과가 없다’가 아니라 대분류 수준에서는 보이지 않고 그 안의 세부 직무 위계로 숨어 있다로 읽어야 하며, 직종 중·소분류×성별 임금 통계 공표가 필요한 이유입니다.

3. 동일 직무 내 초과근로·위험 보상

같은 직종 안의 월 임금 차이를 급여 항목별로 나누면, 정액급여(기본급·고정수당) 차이가 평균 1,147,846원(72%), 초과근로의 대가인 초과급여 차이가 140,869원(9%), 상여금 등 특별급여 차이가 299,906원(19%)입니다. 초과근로에 대한 직접 보상은 격차의 일부이고, 대부분은 기본급에서 생깁니다.

4. 임금 vs 산업재해율

재해율이 높은 산업(농림어업, 운수·창고, 광업)의 시간당 임금은 오히려 평균보다 낮거나 비슷합니다. 위험한 산업일수록 임금이 높다는 ‘위험 프리미엄’이 산업 간에는 뚜렷하지 않습니다. 같은 산업 안에서는 6개 중 5개 산업에서 남성의 재해율이 여성보다 높아, 위험 노출이 남성에 치우쳐 있습니다.

재해율은 업무상 질병(진폐 등 퇴직 후 청구 포함)을 뺀 사고재해 기준입니다. 분자(산재보험 업종 체계)와 분모(임금조사 근로자 수, 표준산업분류)는 출처가 달라 교차표로 맞춘 추정치입니다. 농림어업·운수업은 임금조사가 포괄하지 않는 영세·특수형태 종사자가 분자에 포함돼 과대 추정될 수 있습니다.

5. 격차 요인 분해 (폭포수 차트)

직종×학력×연령×성별 셀(최근 3개년)을 근로자 수로 가중한 회귀모형으로 로그 시간당 임금을 설명하고, 남녀 평균 특성 차이에 계수를 곱해 격차를 요인별로 나눴습니다(풀드 Oaxaca-Blinder). 빨간 막대는 격차를 키우는 요인, 파란 막대는 줄이는 요인이고, 마지막 회색 막대가 같은 조건에서도 설명되지 않는 격차입니다.

직종 모형에서 격차의 47%는 근속 차이, 3.4%는 초과근로 비중, 4.0%는 학력·연령, -4.8%는 직종 분포로 설명되고, 51%는 설명되지 않습니다. 설명되지 않는 부분은 곧 차별을 뜻하지는 않습니다(세부 직무·직급, 측정되지 않은 요인 포함). 다만 정책적으로는 동일노동 동일임금 점검이 필요한 영역의 상한으로 읽을 수 있습니다.

7. 데이터 수집·정제 파이프라인과 방법론

매년(고용형태별근로실태조사) 또는 매월 갱신되는 공공통계를 API로 자동 수집하고, 결측·코드 불일치를 정제해 분석·리포트까지 재생성하는 파이프라인을 구축했습니다. GitHub Actions가 정해진 일정에 파이프라인을 실행하고, 새 연도가 공표되면 이 리포트의 수치와 문장이 자동으로 바뀝니다.

① 수집 collectKOSIS 공유서비스 API(4만 셀 제한 대응 연도 분할), 공공데이터포털 파일데이터 API. 최신 연도 자동 탐지, 증분 수집
② 정제 clean결측·비공개 기호('-','x','…') 처리, 분류 순서 자동 식별, 직종·산업 명칭→표준코드, 산재보험 업종→KSIC 교차표, 단위 통일
③ 검증 QA임금 구성 합계(정액+초과+특별) 대조, 남+여=전체 대조, 미매핑 코드·중복 집계 → 품질 리포트
④ 분석 analyzeshift-share 분해, 던컨 지수, 가중 회귀·Oaxaca-Blinder, 재해율 결합
⑤ 리포트 report결과 수치로 문장·차트를 생성한 단일 HTML(오프라인·인쇄 가능)

분석 방법

  • 시간당 임금 = 월 임금총액 ÷ 월 총근로시간. 집계는 근로자 수×근로시간 가중으로 해 공표 총계와 일치하도록 함
  • 직종 분리 효과: Δ = Σ(sm−sf)·(wm+wf)/2 [분포 차이] + Σ(sm+sf)/2·(wm−wf) [직종 내 차이], 정확 분해
  • 요인분해: ln(시간당임금) = 직종(산업)·학력·연령·연도 더미 + 평균근속 + 초과근로 비중 + 재해율(산업×성별) + 여성 더미, 근로자 수 가중 WLS. 풀드 계수로 Oaxaca-Blinder 분해(Fortin 2008; Jann 2008)
  • 재해율 = 산업×성별 재해자 수 ÷ 같은 산업×성별 근로자 수 × 10,000

한계

  • 개인 단위 원자료가 아닌 공표 집계 셀을 사용한 분석으로, 셀 안의 개인 차이(세부 직무, 경력단절 등)는 통제되지 않음
  • 재해율의 분자(산재 승인)와 분모(임금조사 근로자 수)는 출처·분류체계가 달라 교차표로 맞춘 추정치. 여성의 산재 신청률이 낮을 가능성(과소보고)도 있음
  • 재해율은 산업×성별 수준 변수이므로 ‘같은 산업 안 남녀 위험 차이’로만 식별되며, 인과효과가 아닌 상관 추정치임
  • 교대·야간근무는 근로환경조사 집계 입력 시에만 반영됨
