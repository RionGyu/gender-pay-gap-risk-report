# 수동 입력 자료

API로 제공되지 않는 자료를 아래 형식의 CSV로 두면 정제·분석 단계가 자동으로 읽습니다.

## kwcs_occ_sex.csv — 근로환경조사 직종(대분류)×성별 집계
| 열 | 설명 |
|---|---|
| year | 조사연도 (분석연도와 맞추려면 임금조사 연도 기준으로 기입) |
| occ | 직종 대분류 코드(1~9) 또는 명칭(예: 서비스 종사자) |
| sex | 남/여 |
| shift_rate | 교대근무 비율(0~1) |
| night_rate | 월 1회 이상 야간근무 비율(0~1) |
| hazard_rate | (선택) 위험요인 노출 비율(0~1) |

## injury_ind_sex.csv — 공공데이터포털 키가 없을 때의 산재 집계
| 열 | 설명 |
|---|---|
| year, ind(KSIC 대분류 코드 또는 명칭), sex, injured, fatal(선택) | |
